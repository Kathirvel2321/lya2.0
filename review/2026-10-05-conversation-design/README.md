# Conversation continuity and crystal interface - 2026-10-05

The owner reports that the integrated online LYA conversation now feels successful.
NVIDIA hearing is connected to the real desktop, with Parakeet primary and the
previously qualified Whisper backup. This is an owner report about that session,
not a new controlled accuracy, noise, latency or interruption measurement.
No private words, recording, screenshot, key or runtime identity is copied here.

## Conversation correction

`audio/voice.py` previously searched for a wake name before checking whether the
conversation was active. It could discard context before an interior name, or
turn a name at the end of the question into another wake greeting.

- Active questions now preserve the entire recognized text, including names at
  the beginning, middle or end. Standalone addresses/wake phrases while awake
  extend the conversation silently instead of replaying the greeting.
- A capture begun while awake keeps that context through capture/decoder delay.
  The existing 45-second idle window remains; stop/sleep end it.
- Standalone stop/cancel tolerate transcription punctuation, including `Stop.`.
  Speaking suppression and cancellation still apply.

This fixes routing after recognition. It does not prove recognition accuracy,
recover speech consumed by the local standby wake detector, or add an alarm.

## Native interface

Changed `desktop/app.py` and `desktop/experience.py` using the existing Qt/native
painting path, without new libraries or a rendering engine:

- Preserved crystal artwork/rotation; added a suspended facet base and compact
  nameplate. Preserved the accepted speaking voice.
- Diamond microdots for listening/hearing, crossing thought paths, and a spoken
  wave. Actual voice events drive phase and labels; these shapes do not indicate
  authentication or recognition confidence.
- Faceted graphite panel, restrained edges, native diamond mark, quieter controls,
  visible reply title and clearer paragraph/speaker styles.
- Plain text remains literal; responses never become executable HTML or external
  links. Streaming captions and typing/keyboard controls remain supported.
- Full card height near screen edges, with side placement when space above is
  insufficient. Existing reduced-motion, bounded animation and paint fallback
  remain; no new continuous panel timer or backdrop capture.
