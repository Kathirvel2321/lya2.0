Implemented in `cloud/mobile.html`:

- Scroll through up to 12 exchanges in this page, including the current question/reply. Earlier completed exchanges retain their order. Replies follow the current turn without pulling someone away from older messages they are reading.
- Tap the latest question, or activate it with a keyboard, to prefill the existing text composer. This cancels current capture, playback and pending work. Edit and press Return to resend as a fresh text request; the original completed exchange remains visible. No automatic resubmission and no rewrite of backend conversation context.
- History is only DOM/page memory; no browser persistence, new API or shared memory. Lock, session expiry, backgrounding and pagehide clear it together with the existing draft/reply cleanup. Refresh starts with an empty page; backend RAM history follows its existing policy unchanged.
- Preserve the crystal, existing voice loop, passkeys, providers, limits and desktop behavior. Smaller conversation height at viewports below 450px keeps the composer visible in the tested reduced-height view.
