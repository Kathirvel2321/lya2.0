# Registration command routing — 2026-10-08

Owner reported that requesting register admin returned not connected. The owner supplied the phrase register admijn; the exact live ASR transcript was not independently inspected. Source tracing found that both voice and command dispatch accepted only exact lower-case strings, without stripping transcription punctuation. Consequently Register admin. and other setup phrases could fall through to the ordinary answer route instead of opening the native owner screen. An isolated regression reproduced all twelve tested spoken/typed variants missing the setup route before the fix (baseline.json).

Added one shared, bounded owner-access matcher in desktop/experience.py, used by both dispatch paths. It strips surrounding sentence punctuation and supports the original commands, the owner-supplied admijn spelling, administrator, admin registration, optional please/open/start and a leading LYA address. It only opens the existing proof dialog: no owner session is granted. Questions, negation and mixed action sentences do not trigger the route. General command matching, accepted hearing/voice/UI, startup, models, keys and identity-store rules were preserved.
