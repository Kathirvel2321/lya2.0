# Step 4 foundation and Step 3 visual handoff

## Implemented
- security/approval.py: RAM-only exact challenge binding to full session, person,
  action, raw parameters, random nonce and monotonic deadline (120 seconds).
- Default Brain adapter denies without a trusted verifier. True/False from a verifier
  cannot masquerade as an exact challenge response. Old responses cannot authorize
  a new challenge. Exceptions, expiry and invalidation deny.
- Brain rechecks session equality, active profile and role after approval, before
  private operations. Session clear invalidates pending approvals.
- Existing injected callbacks remain a trusted internal testing seam, not an API
  available to model output or clients. A challenge object alone is not identity proof:
  the future OS/phone adapter must independently authenticate before returning it.
